# AC MART - Official App & Software Store

A turn-key software and web application sales platform built with clean HTML5, CSS3, and JavaScript, featuring instant ABA KHQR checkout, interactive device sandboxes, and a PIN-protected Store Owner Panel.

## 🚀 100% Free Hosting with Vercel (Step-by-Step)

### Option A: Direct Web Upload (Fastest - No Terminal Needed)
1. Go to [https://vercel.com](https://vercel.com) and sign up for a free account.
2. Push your project folder to your [GitHub](https://github.com) account.
3. On Vercel Dashboard, click **"Add New Project"** and select your repository.
4. Click **"Deploy"**.
5. Your website is live in ~10 seconds on `https://your-app-name.vercel.app`!

### Option B: Using Vercel CLI
```bash
npm install -g vercel
vercel
```
